# 知学 ZhiLearn - 幼小衔接识字App

## 简介
专为4-6岁幼儿设计的识字启蒙App，采用「认→写→练」三阶闭环学习法。

## 功能模块
- **首页**：学习进度总览、今日推荐字
- **学习**：三阶闭环（认字→书写→练习）
- **复习**：基于遗忘曲线的智能复习调度
- **统计**：五维雷达图 + 学习报告
- **我的**：学习天数、累计识字数

## 字库
包含80个幼小衔接常用汉字，涵盖：
- 数字（一~十）
- 自然（山、水、火、木、日、月、云、风等）
- 人体（人、口、手、足、目、耳等）
- 动植物（鸟、鱼、虫、牛、羊、马等）
- 生活用品（车、门、书、笔、纸等）
- 颜色（红、黄、绿等）
- 家庭成员（爸、妈、哥、弟、奶等）
- 季节（春、夏、秋、冬）

## 技术栈
- Java 17 + Android SDK 34
- Room 数据库（ORM）
- TextToSpeech 语音合成
- 自定义View（田字格、雷达图）
- GitHub Actions 自动编译

## 本地编译
1. 安装 Android Studio
2. 打开本工程
3. 等待 Gradle 同步
4. 点击 Run 按钮

## GitHub Actions 编译
推送代码到 main 分支后，自动触发编译。
编译完成后在 Actions → Artifacts 下载 APK。
